# cwf-style 实施计划

## 目标

交付一个可独立发布的仓库，包含文风蒸馏 Skill、文章改写 Skill、共用文风库和确定性检查。CWF 总工程只保留架构与集成引用，不作为该仓库的发布内容。

## 已完成

- 双 Skill 的职责边界和三档改写合同已确认。
- 独立 Git 仓库候选目录已创建。
- 文风库、蒸馏、改写和公共边界测试先写并通过。
- 首批两个研究试用档案和一个待补全卡已登记。

## 发布前剩余事项

1. 用户确认许可证。
2. 按白名单复核仓库文件；不纳入 CWF 的内部验证目录、私有样本、凭证和绝对路径。
3. 运行全部测试、空白检查、文风库解析和安装前检查。
4. 恢复 GitHub 网络与用户认证，确认 `wukongai/cwf-style` 是否已存在或允许创建。
5. 提交、推送、只读验证远程提交，并返回真实链接。

## 不在本轮自动完成

- 不把 CWF 总工程的历史文档整体复制进独立仓库。
- 不把意公子、余华或加缪仅凭名字标为可调用模板。
- 不把研究试用或一次改写结果写成已证明的作者复现效果。
- 不在没有许可证和远程目标核对时公开发布。
