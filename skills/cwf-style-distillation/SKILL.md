# 文风蒸馏

这个 Skill 只负责生产可复用的文风档案。它把作品中的材料取舍、整篇推进、叙述关系、语言选择、边界和误用整理成固定版本，再交给共用文风库；它不负责改写一篇现成文章，也不以完成一篇文章作为建档条件。

## 适用入口

使用它处理：

- 从明确指定的公开作者作品中研究一种体裁写法；
- 从本人材料中提炼经确认的长期表达档案；
- 复核已有档案、补充证据、形成新版本；
- 把完整档案登记到 `library/`，供文章改写或原创写作读取。

不要因为用户说“按某作者改一下文章”就启动蒸馏；那是 `cwf-article-rewrite` 的任务。没有足够来源时保留缺口，不按作者名字补写规则。

## 固定流程

1. 明确对象、体裁、时期、用途、授权和观察范围。
2. 整理来源并按作品家族去重，划开发、留出和排除材料。
3. 先读整篇，再拆解材料选择、推进、叙述位置、语言动作、证据、反例和误用边界。
4. 综合成完整表达档案：整篇推进、叙述关系、语言选择；不把“温暖、文学、细腻”当作可执行规则。
5. 独立复核档案范围与证据强度；公开作者保持研究者身份，本人档案遵守确认合同。
6. 冻结版本、生成文风卡和合成短示范，再登记到文风库。

## 输出

交付完整档案、来源与观察范围、规则和反例、体裁限制、原创短示范、研究状态及版本指纹。私有原文留在授权位置；公共仓库只放可公开的档案与脱敏预览。

## 确定性检查

从仓库根目录运行：

~~~bash
PYTHONPATH=. python3 -B -m shared.cli distill validate --request path/to/request.json
~~~

请求必须使用 `cwf-style-distillation-request/v1`，至少包含两个独立作品家族，不得出现文章改写的 `rewrite_mode`。工具只核字段与边界，不证明来源真实或档案效果。

## 交接给文风库

文风库接收固定的档案版本、体裁、规则、完整表达、示范、限制、来源/确认状态和可调用状态。文风库只解析和导出，不为缺失档案补写内容。长期风格反馈形成新蒸馏任务，不从一次改稿自动写回永久档案。
